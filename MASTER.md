# DocuSense AI — Master Specification (MASTER.md)

## 1. Executive Summary
**DocuSense AI** is an Intelligent Document Processing (IDP) and invoice auditing SaaS MVP designed for small business owners, accountants, finance teams, and procurement professionals. It automates invoice ingestion, structured data extraction using Google Gemini, deterministic arithmetic & business-rule validation, duplicate detection, human-in-the-loop review, and auditable financial logging with default INR (₹) representation.

## 2. Core Architecture Principles
1. **Never False Success**: Never report AI extraction as successful if the API fails or output fails schema validation.
2. **Deterministic Financial Validation**: Financial math (`subtotal - discount + tax + charges = total`) is computed deterministically in JavaScript with decimal-safe rules, never delegated to an LLM.
3. **Evidence-Based Oversight**: Duplicate detection, price alerts, and discrepancies flag invoices for human review without declaring fraud unilaterally.
4. **Data Isolation**: Multi-tenant database design where invoices, findings, and audit logs are scoped strictly to the authenticated `user_id`.
5. **Private Document Storage**: Files stored in Supabase private bucket `invoice-documents`, accessed exclusively via signed URLs generated by the backend.

## 3. System State Machine
- **Processing Status**: `Uploaded` -> `Processing` -> `Processed` | `Needs Review` | `Failed`
- **Validation Status**: `Verified` | `Needs Review` | `Failed`
- **Review Status**: `Pending` | `In Review` | `Approved` | `Rejected` | `Resolved`

## 4. Phase Milestones
- **Stage A**: Foundation, database schema, JWT/bcrypt authentication & user ownership.
- **Stage B**: PDF upload, private storage, Gemini extraction with `@google/genai`, deterministic validation, exact duplicate detection, persistence.
- **Stage C**: Human review queue, authorized field corrections, re-validation, review actions, and audit logs.
- **Stage D**: 5 connected dashboard views (Overview, Upload, All Invoices, Review Queue, Insights).
- **Stage E**: Testing suite (Vitest + Supertest), documentation, and deployment readiness.
